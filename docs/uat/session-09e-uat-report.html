💡 Observations

OBS-01: Fix T-014 before the uat → main PR

The admin page is the most privileged screen in the app. Any HTML a seller types is currently treated as page code there. The 9E flag reason gives a second way in, through model output. Recommended: a small fix/admin-escape-listing-fields branch that wraps every user- or model-supplied field in the pending queue (and the reports and feedback views, if they have the same pattern) in escapeHtmlAdm(). Also worth checking how the main app renders listing titles in its own innerHTML templates.

OBS-02: If step 1 of the manual test shows no 🚩 at all

This could be T-015 (Vercel froze the function before the background verdict was saved). Check in Supabase: if the test listing's moderation_scored_at is empty, the background work never finished. The fix would be Vercel's waitUntil() or awaiting the call before responding (about 1s slower posting). Don't change anything unless the manual test actually fails.

OBS-03: Seller email only fires on a buyer's first message per listing

Manual step 3 must use a buyer account that has never messaged that listing before, otherwise no email is sent and the test looks like a failure when it isn't.

OBS-04: Model IDs

Moderation and lead scoring use claude-haiku-4-5-20251001 (Active). Draft reply uses claude-sonnet-5 (legacy, still available). No change needed for this test. A swap is one line per file when Anthropic sends a deprecation notice.
