1Real-Time Chat

B1
Tapping "I'm Interested" and sending a note starts a real chat thread
  1. As a buyer account, open a listing that belongs to a different (seller) account
  2. Tap "I'm Interested", type a short note, send it
  3. Verify: the note sends successfully and the button/UI now shows a way to continue the conversation (not a dead end)
B2
Returning to that listing shows "💬 Chat" instead of "I'm Interested" again
  1. As the same buyer, leave the listing and come back to it (or reload the app)
  2. Verify: the button now says "💬 Chat" (not "I'm Interested" again) and opens the existing thread with your original note as the first message
B3
Seller sees the new conversation in their Inbox and can reply
  1. Log in as the seller account (or switch accounts)
  2. Open Inbox
  3. Verify: the new conversation appears with the buyer's note as the last message, tapping it opens the thread, and you can type + send a reply
B4
Messages arrive live without refreshing (Realtime)
  1. Open the same conversation on two devices/browsers at once — one as buyer, one as seller
  2. Send a message from one side
  3. Verify: the message appears on the other side within a second or two, without needing to reload the page
B5
Seller notification email still arrives on the first buyer message
  1. Using a fresh listing/buyer pair (not one already messaged before), send the first "I'm Interested" note
  2. Verify: the seller receives the existing notification email, same as before Session 6 — the note-first UX didn't break this

2Report Listing

C1
Flag icon is visible on someone else's listing, and the report modal works
  1. Open a listing that belongs to a different account
  2. Tap the flag/report icon
  3. Verify: a modal opens with reason chips (Fake / Wrong price / Spam / Offensive / Other) and an optional note field
  4. Pick a reason, optionally add a note, submit
  5. Verify: a confirmation toast appears and the modal closes
C2
You cannot report your own listing
  1. Open one of your own listings
  2. Verify: either the flag icon is hidden, or attempting to report it shows a clear "you cannot report your own listing" error
C3
Reporting the same listing twice updates your report instead of duplicating it
  1. Report the same listing again with a different reason
  2. Verify: it submits successfully with no error (this updates your existing report rather than creating a second one — you won't see this directly, but it should not error out)
