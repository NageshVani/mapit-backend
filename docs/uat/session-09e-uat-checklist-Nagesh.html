📋 Session 09e Manual UAT: the 4-step AI click-test

This checks that the three AI helpers work with the real mapit-uat key: (1) suspicious new listings get a 🚩 in the admin queue, (2) the ✨ Draft Reply button writes a reply to feedback, (3) genuine buyer messages reach the seller without the [Unscreened] warning, and (4) the cost shows up in the Anthropic Console. Claude's automated pass is in session-09e-uat-report.html (17 pass, 1 fail, 1 warning, 2 skipped).

Test on: https://mapit-backend-git-uat-nagesh-n-arun.vercel.app (the key is only on the uat preview, not on mapit.co.in). Admin page: the same address followed by /admin.

You'll need: your admin account (the seller), a second account to act as the buyer (e.g. a +alias email), and access to the seller account's email inbox.

⚠️ The first page load can take 5–10 seconds because the uat preview "wakes up" slowly. That's normal and not a failure. Also, uat and the live site share one database, so please delete the test listings at the end (step 5).

1Listing check (🚩 flag)

1a
Post an ordinary listing
  1. Sign in as yourself and tap to post a new listing
  2. Use something normal, e.g. title TEST Wooden study table, description Solid teak table, 2 years old, minor scratches. Pickup from Jayanagar.
  3. Fill in the rest of the form and submit
  4. Expected: you see "Listing submitted for review", the same as always. Posting should not feel any slower than before.
1b
Post an obviously spammy listing
  1. Post a second listing with title TEST EARN 50000 DAILY!!! WORK FROM HOME
  2. Description: No selling needed. Click bit.ly/xyz and send Rs 999 registration fee on WhatsApp to start earning today!!!
  3. Submit it
  4. Expected: it is accepted the same way as the first. The AI never blocks a post; it only adds a warning flag for you to see.
1c
In the admin queue, the spammy listing is flagged 🚩 and sits at the top
  1. Wait about 10 seconds, then open the admin page (/admin) and go to the pending listings to review
  2. Expected: the spammy listing is at the top with a red 🚩 Flagged: … label and a short reason (e.g. "get-rich-quick spam")
  3. Expected: the ordinary table listing is also there, with no 🚩 label
💡 If neither listing shows a label after a refresh, mark Fail and tell James. It probably means the server stopped before the AI check finished (report item T-015), and James will check the database to confirm.

2Feedback ✨ Draft Reply

2a
Draft Reply writes a sensible reply, but doesn't send it
  1. If there is no recent feedback to use: as the buyer account, open the Feedback form in the app and send something like TEST The map takes long to load on my phone
  2. On the admin page, open the Feedback viewer and find that feedback
  3. Tap ✨ Draft Reply and wait a few seconds
  4. Expected: a 2–4 sentence, polite reply appears in the reply box. It refers to the actual issue and ends with "— The MapIt Team".
  5. Expected: nothing is sent yet. The reply only goes out if you press the separate Send Reply button. You can edit it, or just leave it unsent.
💡 A message like "Could not generate a draft reply right now" means the key isn't working on uat. Mark Fail.

3Buyer message screening

3a
A genuine "I'm interested" message: the seller email has no warning
  1. Pick a live listing that belongs to your seller account (approve the TEST table from step 1 if that's easiest)
  2. Sign in as the buyer account. It must be an account that has never messaged this listing before, because the email only goes out on the first message.
  3. Tap "I'm interested" and write something genuine, e.g. Hi, is the table still available? Can I see it this Saturday morning?
  4. Check the seller's email inbox (give it a minute)
  5. Expected: the subject starts with the buyer's name, without "[Unscreened]" in front
  6. Expected: there is no orange "⚠️ This message hasn't been automatically verified…" box in the email
3b
(Optional) A spammy message still gets the warning
  1. Use a different listing (or a third account), since again only the first message triggers an email
  2. Send: Buy cheap followers now!!! visit bit.ly/promo123
  3. Expected: this email does have "[Unscreened]" in the subject and the orange warning box. This shows the check really tells the two apart.

4Cost shows up

4a
The Anthropic Console shows a few cents of usage
  1. Open platform.claude.com → Usage (or Cost) for the Nakshe Ventures org
  2. Expected: today shows a small amount of usage on the mapit-uat key, a few cents at most. Billing should show the $5 credit barely touched.
💡 Usage can take a few minutes to appear. If it's blank, check again in 10–15 minutes before marking Fail.

5Clean up

5a
Delete the TEST listings
  1. On the admin page, reject or delete the spammy "EARN 50000 DAILY" listing
  2. Delete the TEST table listing too (from My Listings, or in the admin page)
  3. Expected: neither listing appears on the map on mapit.co.in. This matters because uat and the live site share the same database.
