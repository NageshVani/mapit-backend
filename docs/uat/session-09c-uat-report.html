💡 Observations

OBS-01: The T-027 pattern may exist on other tables

Row-level security decides which rows a user may change, not which columns. Any table with an "update your own row" policy (for example listings) may let a user change columns the app never meant them to, such as a moderation status. Migration 017 only covers profiles. Check every table in the pre-launch security audit. Outside 9C's scope.

OBS-02: Testers on one Wi-Fi can hit the network limit

The send-code route allows 10 requests per hour from one IP address. Family testers sharing a home connection can see "Too many code requests from this network". This is working as designed. Switch the phone to mobile data if it happens.

OBS-03: One stray real WhatsApp code during testing

During an earlier re-run on 2026-10-08, one real code went to 9844221362 from a throwaway account (since deleted). The script now refuses to send to any number not on its fake-number allow-list.

OBS-04: Migration 017 is already live for production

uat and production share one Supabase project, so 017 applies to mapit.co.in too. Production's code writes to profiles only through the server (service-role key), so nothing there should break. Mention 017 in the uat → main pull request.
