2POI Proximity ("📍 Nearby" on listing detail)

B1
Posting a listing in a built-up area shows nearby school/mall/supermarket

  2. Open that listing's detail view a few seconds later (the lookup runs in the background after posting)
  3. Verify: a "📍 Nearby" section appears below the description showing at least one of school/mall/supermarket with a distance like "450m" or "1.2km"
B2

  2. Open that listing's detail view

3Same-Location Stacked Pin

C1
Two+ listings at the exact same spot show one badged pin, not overlapping pins
  1. Post 2–3 test listings at the exact same GPS coordinates (e.g. reuse the same saved pin/address for all of them)
  2. Look at the map
  3. Verify: you see one pin with a small orange badge showing the count (e.g. "3"), not multiple pins stacked on top of each other
  4. Tap the pin
  5. Verify: a popup opens with a scrollable mini-list of all the listings at that spot; tapping one opens its full detail
C2
Clicking around elsewhere doesn't corrupt the stacked pin's badge/count (regression re-check)
  1. With a stacked pin visible on the map (from C1), click an unrelated single listing somewhere else
  2. Verify: the stacked pin still shows the correct badge and count afterward — it hasn't silently reverted to a plain single-listing icon

4Location Picker — Post Listing & Registration

D1

  1. Start posting a new listing, choose "Select location manually…"
  2. Type an area name into the search box — verify the map pans/zooms there (pin doesn't move yet)
  3. Tap on the map to drop the pin — verify the address updates and a marker appears
  4. Now paste a known GPS coordinate pair into the "paste GPS coordinates" field (e.g. from a Google Maps long-press)
  5. Verify: the pin jumps to match the pasted coordinates, and whichever method you used last is what actually gets submitted with the listing
D2
Registration home-location step has the same search + tap + paste options
  1. Register a new test account (or reset an existing test account's home location if that's easier)
  2. On the home-location step, verify all three options are present: search box, tap-to-drop-pin, and paste-GPS-coordinates
  3. Verify: whichever you use last correctly sets your home location, and "Skip for now" is still reachable without scrolling
